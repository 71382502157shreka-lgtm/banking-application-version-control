Understand how BankVCS 2.0 maintains zero data loss and role isolation

BankVCS 2.0 records every database mutation as a discrete version snapshot (`v1 → v2 → v3`). If an accidental corruption or invalid transaction occurs, administrators can review field-level diffs and execute an immediate forward rollback without losing transaction history.
