# Use Cases (summary)

## Customer
- Register / Login / Logout
- View dashboard and account balances
- Deposit / Withdraw / Transfer funds
- Add / Edit / Deactivate beneficiaries
- View own transaction and version history
- Change password, update profile

## Employee
- View customer accounts and transactions
- View version history and audit logs
- Flag/verify suspicious transactions (via reversal workflow)

## Admin
- Manage users (activate/deactivate)
- View all accounts, transactions, versions, and audit logs
- Compare any two versions of a record
- Restore eligible non-financial records to a prior version
- View system-wide statistics
