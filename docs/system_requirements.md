# System Requirements

## Hardware
- Any machine capable of running Python 3.10+ and a local SQLite database.

## Software
- Python 3.10 or later
- pip
- VS Code (recommended) or any code editor
- A modern web browser

## Development dependencies
See `requirements.txt`: Flask, Flask-SQLAlchemy, Flask-Login, Flask-WTF,
Werkzeug, python-dotenv, pytest.
